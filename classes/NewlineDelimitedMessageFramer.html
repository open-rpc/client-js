    Class NewlineDelimitedMessageFramer

    Newline-delimited JSON framing: one JSON message per line, delimited by \n, no embedded newlines. This is the framing used by MCP stdio and ACP. JSON.stringify escapes any newlines inside string values, so the "no embedded newlines" rule holds for free.
